## Data

This project uses the open **High-throughput Shampoo Formulations Dataset**: 812 liquid shampoo formulations built from 18 ingredients (12 surfactants, 4 conditioning polymers, 2 thickeners). Each formulation includes ingredient composition and phase stability. The 294 stable formulations also have turbidity (a proxy based on UV-vis absorbance, with uncertainty) and rheology measurements, including full viscosity vs. shear rate curves.

- **File used:** `LiquidFormulationsDataset_2023.json`
- **Source repository (figshare):** https://doi.org/10.6084/m9.figshare.c.7132624.v1
- **Data descriptor paper:** https://doi.org/10.1038/s41597-024-03573-w
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/

### Data fields

| Field | Description |
|---|---|
| 18 ingredient columns | Ingredient amounts in each formulation |
| `Stability_Test` | Phase stability (true/false) |
| `Turbidity_NTU`, `Turbidity_Error` | Proxy turbidity and its uncertainty (stable samples only) |
| `Viscosity` | Zero-shear viscosity class: VERY-LOW, LOW, MEDIUM, HIGH |
| `Rheology_Type` | NEWTONIAN, SHEAR-THIN, or OTHER |
| `Rheology_Data` | Shear rate, average viscosity and standard deviation |
| `ID` | Unique sample ID |

Unstable samples have `"NA"` for the property fields. Ten of the 822 prepared formulations were excluded by the authors, which leaves 812 (see Table 1 of the paper).
